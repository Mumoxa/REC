# Claude Code / Claude Agent Instructions

Read and obey `AGENTS.md` before performing any REC research or implementation work.

Critical rule: a missing local `.env` or ingest key is not a reason to stop a recruitment run. Use the repository's `npm run rec:publish -- <payload>` publication command, which bootstraps the live REC connection through Vercel.

Do not end a qualifying recruitment run at vacancy discovery, QA Gate A or payload generation. Continue through candidate mapping broadly: build the credible market (target 50+ where supported), pass QA Gate D, form the strongest-market layer (normally ~20–25), then derive the final client-submittable Top 10 subset and verify REC persistence. Top 10 alone is not a completed candidate market.
