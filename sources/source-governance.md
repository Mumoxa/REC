# Source Governance

## Non-negotiable hierarchy

The source registry is not a flat list.

### Tier 1 — agreed Talent Tree clients

Highest commercial priority. Search client-specific sources before broad-market work in each discovery lane.

### Tier 2 — mandatory priority agencies

Exhaustively review:

1. PRN Staffing;
2. Communicate Recruitment;
3. Network Recruitment.

Do not sample these sources.

### Tier 3 — broader South African source universe

The source-map specification records **350 reusable sources/channels**.

Internal order:

1. Critical scraper priority;
2. High;
3. Medium;
4. Low;
5. unspecified if any.

Within a level prefer stronger evidence and original employer/recruiter sources over aggregators.

### Tier 4 — long-tail discovery

Includes web/X-ray, social posts, niche professional bodies, trade associations, industry media, employer newsrooms, ATS pages found through search engines, and credible community channels where accessible.

## Search completeness

A source counts as searched only when at least one is true:

- its live vacancy inventory was reviewed;
- relevant category/location filters were reviewed;
- a defensible source-specific query/search was executed;
- the source was verified inactive/unavailable and recorded.

Opening a homepage does not count.
