# Employer Attribution Protocol

Employer attribution is required when the advertiser is an agency, recruiter, consultancy, RPO or otherwise hides the end client.

## Phase A — extract a vacancy fingerprint

Capture:

- exact title;
- exact location;
- industry/subsector;
- company scale clues;
- products/services;
- ERP / software / systems;
- qualifications;
- reporting line;
- team size;
- P&L / budget clues;
- international exposure;
- regulatory clues;
- salary;
- working model;
- unusual duties;
- rare terminology;
- distinctive wording;
- recruiter / consultant identity;
- reference number.

## Phase B — build candidates

Search using distinctive clues before generic combinations.

Candidate sources can include:

- exact/near-exact wording elsewhere;
- agreed-client career pages;
- employer ATS pages;
- LinkedIn posts and LinkedIn Jobs;
- duplicate agency adverts;
- historical vacancies;
- corporate expansion or restructuring evidence;
- organisational structure;
- incumbent / leadership evidence.

Do not prematurely select one employer.

## Phase C — test candidates

For each serious candidate compare the complete vacancy and actively search for contradiction:

- wrong location;
- wrong industry;
- wrong systems;
- wrong company scale;
- incompatible reporting line;
- current incumbent;
- timing mismatch;
- another direct employer advert;
- qualification mismatch;
- structural contradiction.

## Output states

- **CONFIRMED**
- **PROBABLE**
- **HYPOTHESIS**
- **UNKNOWN**

Never manufacture exact probabilities unless a calibrated model exists.

For unresolved senior roles, retain a shortlist with supporting evidence, weaknesses and contradictions.
