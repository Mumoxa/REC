# Canonical Vacancy and Deduplication Rules

A single vacancy may appear as a company post, hiring-manager post, employee repost, LinkedIn Job, employer careers page, agency advert, job board listing or search result.

Do not create separate commercial opportunities for the same vacancy.

## Compare

- normalised employer;
- normalised title;
- location;
- employment type;
- posting-date proximity;
- recruiter reference;
- wording fingerprint / rare phrases;
- salary;
- requirements;
- application URL;
- application email;
- hiring manager;
- source chain.

## Canonical record

Prefer the earliest identifiable original source as the canonical source where defensible.

Retain duplicate source records beneath the canonical vacancy because duplicates can provide:

- employer-attribution evidence;
- date/freshness evidence;
- recruiter/client clues;
- salary or requirements omitted elsewhere.

## Safety rule

Avoid aggressive merging. Incorrectly merging two separate vacancies is more damaging than retaining an unresolved possible duplicate.
